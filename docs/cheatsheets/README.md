# Role Cheat-Sheets · রোল গাইড

One-page training sheets, one per role. Print or share with staff. Each lists
only the screens that role actually uses (matching the in-app role scoping).

| Sheet | Role | Training time |
|---|---|---|
| [1-salesman.md](1-salesman.md) | Salesman / সেলসম্যান | ~30 min |
| [2-accountant.md](2-accountant.md) | Accountant / হিসাবরক্ষক | ~1.5 hr |
| [3-manager.md](3-manager.md) | Manager / ম্যানেজার | ~2 hr |
| [4-owner.md](4-owner.md) | Owner / মালিক | Phased |
| [5-customer-portal.md](5-customer-portal.md) | Customer Portal | ~5 min |

**Tip:** New dealers start in **Simple** menu mode (Settings → Menu Mode), so staff
see only core daily modules. Switch to **Advanced** to unlock growth, HRM, and
advanced finance as the business grows.

To produce printable PDFs, open each file in any Markdown viewer and print to PDF.
