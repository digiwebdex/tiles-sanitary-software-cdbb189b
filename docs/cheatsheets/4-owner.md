# Owner (Dealer Admin) Cheat-Sheet · মালিক গাইড

**Your job / আপনার কাজ:** Oversee everything, configure the system, control access.
**Training:** Phased — learn module-by-module, not all at once.

---

## Start here / শুরু করুন
1. **Settings → Menu Mode** — নতুন হলে **Simple** রাখুন (কম মেনু, সহজ)। অভ্যস্ত হলে **Advanced** করুন।
2. **Settings** — কোম্পানির নাম, BIN/ট্যাক্স, VAT রেট, ব্যাকঅর্ডার সেট করুন।
3. Dashboard এর **Setup Checklist** (golden path) ফলো করুন:
   Products → Customer → Supplier → Purchase → Sale → Collection → Supplier payment.

---

## Module phases / ধাপে ধাপে চালু করুন
| Phase | Modules |
|---|---|
| **1 — Daily (Simple)** | Products, Customers, Suppliers, Purchase, Sale/POS, Collection |
| **2 — Control** | Stock, Challans, Deliveries, Returns, Payables, Day-End |
| **3 — Accounts** | Ledger, Cashbook, Bank, VAT/Mushak, Financial Statements |
| **4 — Growth (Advanced)** | Leads, Quotations, Projects, Campaigns, Customer Portal |
| **5 — Advanced** | HRM, EMI, Directors, Journal, Warehouses |

> Phases 4–5 only appear in **Advanced** menu mode.

---

## Manage your team / টিম ব্যবস্থাপনা
- **Settings → Roles / Users** — স্টাফ যোগ করুন ও role দিন:
  - **Salesman** — শুধু বিক্রি ও কালেকশন
  - **Accountant** — টাকা ও রিপোর্ট
  - **Manager** — পুরো অপারেশন
- প্রতিটি role শুধু তার দরকারি মেনু দেখে — কম বিভ্রান্তি।

## Money oversight / আর্থিক নজরদারি
- **Dashboard → Financial Summary** — receivable, payable, cash, stock value
- **Financial Statements** — P&L, ব্যালেন্স শিট
- **Subscription** — প্ল্যান ও মেয়াদ দেখুন

---

## Tips / টিপস
- নতুন স্টাফকে আগে **Demo** এ প্র্যাকটিস করান, পরে আসল অ্যাকাউন্টে।
- মাসে একবার **Backup** নিন (Settings → Data Backup)।
- বকেয়া বেশি হলে **Reminders** পাঠান।
